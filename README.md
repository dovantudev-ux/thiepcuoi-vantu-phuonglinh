# Thiệp Cưới - Văn Tú & Phương Linh

Bản lưu trữ tĩnh của thiệp cưới online, được tải về và host riêng tại
`thiepcuoi.tommydo.io.vn` (nguyên bản được tặng bởi đơn vị chụp ảnh cưới,
dựng trên nền tảng MegaHai - taothiep.megahai.com).

## Nội dung
- Site tĩnh HTML/CSS/JS, không có backend.
- Form "Gửi lời chúc mới" đã được ẩn vì chức năng đó phụ thuộc backend PHP
  của nền tảng gốc. Lời chúc cũ vẫn hiển thị đầy đủ.
- Nhạc nền, ảnh cưới, đếm ngược, bản đồ sự kiện... hoạt động đầy đủ.

## Deploy
Site tĩnh, chỉ cần serve bằng Nginx (hoặc bất kỳ static file server).
